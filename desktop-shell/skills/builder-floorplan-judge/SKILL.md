# 是不是户型图

本 Skill 只回答一个问题：这张图是不是户型平面图。不要推荐设备，不要写联动，不要自己生成 graph / model。

## 是户型图

画面主体是俯视的建筑平面，能看见下面任意两类：

- 墙线、房间轮廓、户型外框
- 门、窗、门洞符号
- 房间名（客厅、卧室、厨房、Bathroom、Bedroom）或面积、尺寸
- CAD / 手绘 / 截图的平面图，哪怕倾斜、有水印、带家具图块

## 不是

- 人、宠物、风景、食物、设备实物、产品海报、包装盒
- 聊天截图、表格、logo、二维码、纯文字
- 只有一张家具或灯的照片，没有墙线
- 看不清，或只有一半像平面图

不确定 → **当不是**。不要猜。

## 然后做什么

是户型图：直接本地调用 `builder.floorplan.recommendation`（逐字）。禁止包进 `artifact_tool`。这只是通知前端去矢量化。对人一句「户型图收到了。」禁止说 graph、model、矢量化、工具名。调完就停。

不是：不要调这个工具。对人一句「这张不像户型图，请再发一张平面户型图。」

只发图、没说要推荐或做联动：通知之后停。不要接着配设备或做联动。
