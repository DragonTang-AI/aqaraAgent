# 对用户推荐表模板（聊天通道必用）

编排层渲染；**禁止**只输出「房间 | 面积 | 推荐设备」三列汇总表。  
必须按 **设备一行一条** 输出明细（可从 `devices[]` 直接展开）。

## 总览（一两句）

已整理推荐清单（××档），共 N 个房间、M 台设备。目录暂无标价，以门店为准。

## 明细表（固定列）

| 房间 | 设备 | 推荐理由 |
|------|------|----------|
| 客厅 | 网关 | 给全屋子设备组网 |
| 客厅 | 人体传感器 P1 | 覆盖动线，便于人来开灯 |

列来源：

| 列 | 字段 |
|----|------|
| 房间 | 聊天可给真实 `roomName` 附面积；机器 JSON 仍只写 model 原始 `roomName` |
| 设备 | `productName` × `qty`（跟人话语种：英文会话用 lookup `--lang en` 的品名） |
| 推荐理由 | `rationale` |

`model` / `protocols` / `needsGateway` **只写 JSON**，禁止出现在对人表里。
