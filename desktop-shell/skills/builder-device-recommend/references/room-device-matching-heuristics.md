# 房间-设备匹配启发式（可调整）

从 `device-index` 的 categoryId 路由；打开类文件后选具体 model。

## 全屋综合（默认舒适档）

| 区域类型 | 建议类别（categoryId） | 说明 |
|----------|------------------------|------|
| 全屋 | 1 网关中控 | 至少 1；大户型可建议 2 |
| 入户/客厅/走廊 | 151 人体传感器 | 动线 |
| 门（入户/阳台门） | 152 门窗传感器 | **门多才加**：该房门≥2 或门+窗≥3；门少不加 |
| 各主要房间照明 | **101 智能灯具（空房必选）**；已有传统灯再补 51 墙开 | 禁止用插座代替灯 |
| 厨房 | 154 水浸 + 156 燃气（若意图含安全） | |
| 卫生间 | 154 水浸（可选） | |
| 卧室 | 153 温湿度（可选）；窗帘 301（若有窗且用户要舒适） | |
| 客厅窗 | 301 窗帘电机（可选） | |

## 意图裁剪

- 「只要安防」：网关 + 门窗 + 人体 +（可选）摄像机，不灌全屋灯控
- 「只要灯光」：网关策略 + 开关/灯具 + 关键人体
- 用户点名房间：只给点名房间（对 `properties.name` / Bedroom2）+ 必要时 1 个全屋网关；禁止把客厅等未点名房间写进表
- 「只要传感器」：用 `intentPresets.侧重安防`，不要每间再铺灯
- 老人/小孩：卧室人感、卫生间水浸优先，少气候
- 禁止多间房同一套品类+同一句理由

## 选型

- 同 category 多 model：优先 `requiresGateway` 与协议常见、displayName 含主流系列；代表 SKU 用 index 的 `representativeSkuId`
- `typicalSpaces` 在库中多为空——勿依赖，用本表启发式

## placement_ref

格式：`rec_{roomToken}_{role}_{nn}`，同一次推荐内唯一，例如 `rec_living_motion_01`。
