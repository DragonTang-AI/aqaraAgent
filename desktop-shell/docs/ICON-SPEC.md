# Aqara 空间智能桌面端 · 品牌图标交付规格

> 给设计师的图标交付清单。做 macOS（Electron）桌面应用图标，以及启动画面、托盘等配套资产。

---

## 一、最少需要（1 个文件就够）

| 项 | 要求 |
|----|------|
| **格式** | **PNG（首选）** 或 **SVG 矢量源（最佳）** |
| **尺寸** | **1024 × 1024 px** |
| **背景** | **透明**（除非品牌本身需要一个底色方块） |
| **色彩空间** | sRGB |
| **内容** | 品牌图标主体居中，四周留白约 10%（见下方规范） |

> 拿到这一份，我就能自动生成 macOS 需要的所有尺寸和 `.icns` 打包图标。

---

## 二、如果方便，更全的交付（可选）

### 1. 多尺寸 PNG（一组）
`16 / 32 / 64 / 128 / 256 / 512 / 1024` px，命名如
`aqara-appicon-{size}.png`。

### 2. macOS .iconset（如果设计师会用 `iconutil`）
需要以下 10 个文件（同一图，不同尺寸）：

```
icon_16x16.png      (16)      icon_16x16@2x.png      (32)
icon_32x32.png      (32)      icon_32x32@2x.png      (64)
icon_128x128.png    (128)     icon_128x128@2x.png    (256)
icon_256x256.png    (256)     icon_256x256@2x.png    (512)
icon_512x512.png    (512)     icon_512x512@2x.png    (1024)
```

### 3. 直接给 .icns
macOS 打包图标（`aqara-appicon.icns`）。不会做的话跳过，我来生成。

## 三、macOS 图标设计规范

| 项 | 建议值 |
|----|--------|
| 画布 | 1024 × 1024 px |
| 图标主体（圆角方） | **824 × 824 px**，居中 |
| 四周留白 | 每边 **100 px**（透明） |
| 圆角半径 | 约 **185 px**（连续圆角 / squircle，不要用普通圆角） |
| 背景 | 透明（圆角方块本身可带品牌底色） |

> 简化记忆：**1024 画布 + 主体居中 + 每边留白约 10% + 大圆角**。
> 不确定的话，就直接给「1024×1024 透明底 + 主体居中」，裁切/圆角我来兜底。

### 明暗主题（可选）
若品牌有浅色版 / 深色版，各给一份（例如深色模式下用亮色图标）。

---

## 四、其他配套资产（用到再要，尽早知会设计师更好）

| 资产 | 用途 | 规格 |
|------|------|------|
| **启动画面 Logo** | 应用启动时黑底 loading 页 | 透明底、**浅色/白色版**，SVG 或 512×512 PNG |
| **系统托盘图标** | 菜单栏常驻（如后续做托盘） | **单色模板图**，`16×16` + `32×32(@2x)`，命名 `trayTemplate.png` / `trayTemplate@2x.png` |
| **品牌字标 wordmark** | 关于页 / 托盘菜单 / 启动页 | 透明底 PNG + SVG，浅色 & 深色各一份 |
| **窗口图标** | 窗口左上角（Windows 用） | 256×256 PNG |

---

## 五、命名建议

```
aqara-appicon.svg            # 矢量源（最佳）
aqara-appicon-1024.png       # 主图标（透明底）
aqara-appicon.icns           # macOS 打包图标（可选）
aqara-logo-light.svg         # 浅色版（深色背景上用）
aqara-logo-dark.svg          # 深色版（浅色背景上用）
trayTemplate.png / @2x       # 托盘模板图（可选）
```
